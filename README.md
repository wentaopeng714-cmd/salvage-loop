# Salvage Loop

A standalone resource-chain incremental game with survivor assignment, offline progress, and autosave. Open `index.html` directly.

Based on the incremental structure of [Shpigford/society-fail](https://github.com/Shpigford/society-fail) by Sabotage Media LLC. MIT License; the original license is preserved in `LICENSE`. This edition replaces the setting, resource chain, progression rules, palette, layout, copy, and audio.
